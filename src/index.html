Capabilities

Vehicle data points mapped to Homey capabilities. Each row shows the capability, the value as the Homey app derives it, and the raw attribute(s) it is read from. Where the Homey app falls back through several attributes, the one actually used is shown. Lock, door, window and sunroof state only travel over the Homey app's WebSocket push connection and never appear in the REST data this tool reads, so those rows are greyed out. Rows marked Proposed are capabilities requested on GitHub that the Homey app does not have yet; they show whether your car reports the attribute the capability would read (see todo.md).

Unmapped Raw Attributes

Attributes the Mercedes API returned for this vehicle that no Homey capability reads. These are candidates for new capabilities in the Homey app. Only attributes that carried a value are listed; the REST endpoint this tool reads returns a subset of what the Homey app receives over its push connection, so the list is not exhaustive.

Logic Flows

Homey flow cards provided by the app. Actions send commands to the car, conditions check the current capability values, and triggers fire when the vehicle state changes. Arguments and tokens are listed where a card has them; deprecated cards still exist for old flows but no longer work, and cards marked Proposed are requested but not in the app yet.
